# Propfy

**PT** — O Propfy nasceu de uma necessidade real: ajudar corretores autônomos a organizarem seu dia a dia sem depender de cadernos ou anotações dispersas. O app reúne imóveis, clientes, visitas e contratos em um único lugar, com alertas automáticos de vencimento e reajuste de aluguel.

**EN** — Propfy was born from a real need: helping autonomous real estate brokers organize their daily work without relying on notebooks or scattered notes. The app brings together properties, clients, visits and contracts in one place, with automatic alerts for contract expiration and rent readjustment.

---

## Tecnologias

- React Native + Expo
- Node.js + Express
- Firebase (Firestore)
- Jest
---

## Funcionalidades

- [x] Dashboard com contadores em tempo real
- [x] Cadastro e gestão de imóveis com detalhes
- [x] Cadastro e gestão de clientes com filtros por tipo
- [x] Agendamento de visitas com status e observações
- [x] Gestão de contratos com alertas de vencimento e reajuste anual
