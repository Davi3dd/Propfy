# Propfy

> Agenda imobiliária pessoal para gerenciar imóveis, clientes, visitas e contratos.

---

## Sobre o projeto

O Propfy é um app mobile desenvolvido para corretores de imóveis organizarem seu dia a dia em um só lugar. Sem login, sem complicação — simples e direto ao ponto.

---

## Funcionalidades

- [ ] Cadastro de imóveis com endereço, valor e tipo
- [ ] Cadastro de clientes com contato e interesse
- [ ] Agendamento de visitas com status em tempo real
- [ ] Contratos com alerta de vencimento
- [ ] Aviso de reajuste anual de aluguel

---

## Status das visitas

Agendada → Confirmada → Realizada → Fechada

---

## Tecnologias

- **Mobile:** React Native + Expo
- **Backend:** Node.js + Express
- **Banco de dados:** Firebase (Firestore)

---

## Como rodar

### Pré-requisitos
- Node.js v18 ou superior
- Git
- Expo Go instalado no celular

### Clonando o projeto

git clone https://github.com/Davi3dd/Propfy.git
cd propfy

### Rodando o backend

cd backend
npm install
npm run dev

### Rodando o app

npm install
npx expo start

Escaneie o QR code com o app Expo Go no celular.

---

## Variáveis de ambiente

Crie um arquivo .env dentro de /backend:

PORT=3000
FIREBASE_PROJECT_ID=
FIREBASE_CLIENT_EMAIL=
FIREBASE_PRIVATE_KEY=
