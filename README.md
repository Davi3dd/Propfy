# Propfy

Agenda imobiliária pessoal para corretores gerenciarem imóveis, clientes, visitas e contratos.

---

## Tecnologias

- React Native + Expo
- Node.js + Express
- Firebase (Firestore)

---

## Funcionalidades

- [ ] Cadastro de imóveis
- [ ] Cadastro de clientes
- [ ] Agendamento de visitas
- [ ] Gestão de contratos
- [ ] Alertas de vencimento e reajuste
